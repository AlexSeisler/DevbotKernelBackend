## 🔧 Patch Instruction Format (v4.1 Final)

Each PATCH request must include:

```
{
  "repo_id": "owner/repo",
  "branch": "main",
  "file_path": "path/to/file.py",
  "base_sha": "abc123...",
  "patches": [
    {
      "anchor": "func_name",
      "anchor_path": ["MyClass", "func_name"],
      "patch_strategy": "insert",
      "code_block": "    print('Hello from DevBot')"
    }
  ]
}
```

Patch strategies:

- `insert` = top of anchor node
- `append` = bottom of anchor node
- `replace` = requires `anchor_lines`
- `delete` = requires `anchor_lines`, no code_block

Reference: `patch-strategy-guide.txt`
